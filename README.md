# Calorie Counter

## Project Description

The Calorie Counter is a web application that allows users to track their daily calorie intake. Users can add food items, view the total calories consumed, delete food items, and save their data using localStorage.

## Features

- Add food items
- Display a list of food items
- Calculate total calories
- Delete food items
- Reset all data
- Save data using localStorage
- Fetch API integration

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- DOM Manipulation
- localStorage
- Fetch API

## How to Run

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Start adding food items.
