#  Calorie Counter Web App

A simple and user-friendly web application designed to help users track their daily calorie intake, manage food entries, and monitor their eating habits.

##  Features

- **Add Food Items:** Record food items and their calorie values.
- **Track Calories:** Automatically calculate total daily calorie intake.
- **View Food List:** Display all added food entries.
- **Delete Items:** Remove individual food entries.
- **Reset Data:** Clear all saved food records.
- **Local Storage:** Automatically save data using browser localStorage.
- **Fetch API Integration:** Retrieve data through API requests.

##  Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- DOM Manipulation
- Browser Local Storage
- Fetch API

##  Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone https://github.com/sirdrick037-svg/Calorie-couter-WebApp.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Calorie-couter-WebApp
   ```

3. Open `index.html` in your browser.

4. Start adding food items and tracking your calories!
